# Prototype Hub 已确认的分期开发计划

整理日期：2026-09-07。本文固化产品规划会话中已确认的八期计划，替代初始路线中的 M0–M4 排期口径；功能背景及需求编号仍可参考 [PRD](PRODUCT_PRD.md) 和 [初始需求清单](PRODUCT_ROADMAP.md)。

会话分工及文档阅读顺序见 [文档入口](README.md)。本文记录已确认规划，不自动授权开发会话启动未确认的后续期次。

## 已确认方向

- 个人使用优先；团队权限和共享后续考虑。
- 平台保存文件副本，本地编辑后上传新版本或新修订。
- 先完善资产管理，再开发比对。
- 沿用现有 API、Worker、数据库、对象存储和界面风格，每期保持应用可独立使用。
- 逐期开发、逐期验收；每期结束后等待用户确认下一期。

## 分期范围与验收目标

| 期次 | 开发范围 | 验收时应看到的结果 |
| --- | --- | --- |
| 第一期：基础可信性修正 | 原型原件下载、稳定编号、显式基线、历史搜索定位、保存/预览状态和发布文案、首次备份恢复验证 | 历史原包可下载；删除最高版本后编号继续递增；搜索 v2 内容进入 v2 |
| 第二期：删除恢复与完整导出 | 项目/原型/版本统一回收站、恢复关系、对象清理失败重试、项目与版本导出、备份恢复流程固化、关键操作记录 | 恢复项目时找回原型和材料；导出文件齐全；清理失败状态可查 |
| 第三期：项目资料库与材料修订 | 独立资料库与上传、材料资产及修订历史、同项目跨版本引用、引用升级、重复内容提示、旧材料迁移 | 无原型也能存文档；同资料可供多个版本引用；更新资料不改变旧引用 |
| 第四期：发布快照与整套回滚 | 发布清单确认、不可变快照、固定历史入口与当前发布入口、回滚、引用删除保护、快照导出 | 发布 r1 后修改资料，r1 保持原样；回滚时原型和材料一起切换 |
| 第五期：资产查找与数据浏览 | 搜索分页/片段/筛选、最近打开、图片网格和属性、CSV/JSON/SQL 归档预览、XLSX 工作表浏览 | 超过 100 条仍可继续查找；图片可浏览筛选；表格可按工作表查看 |
| 第六期：离线基础比对 | 逐文件哈希、新增/删除/修改清单、材料修订差异、A/B 选择、页面配对、独立并排预览、基础结果导出 | 同大小不同内容能识别；重新打包同内容不误报；对应页面可并排查看 |
| 第七期：视觉与文本差异 | 固定环境截图、页面/图片叠加及差异区域、动态区域忽略、文本/PDF 基础差异、比较任务与离线报告 | 相同页面重比稳定；变化可复核；加载失败明确为比较未完成 |
| 第八期：文档与数据结构比对 | DOCX 段落/表格、XLSX 工作表/值/公式、CSV 主键记录、JSON 结构比较及能力限制 | 公式变化与显示值变化可区分；插行、排序、空值规则明确 |

第四期完成后，用一个真实项目走完一次完整迭代，验收稳定个人版。第五期之后仍分别立项验收，不连续打包开发。

第七期先页面/图片、再 PDF；第八期 DOCX 与 XLSX 分别验收，按文件类型分批交付。

## 第一期范围与状态

第一期开发已交付，用户验收尚待确认；实现、验证及迁移证据见 [第一期交付说明](PHASE1_DELIVERY.md)。原始开发边界如下，供验收追溯：

1. `GET /api/v1/versions/:versionId/download` 受登录及所有权保护，返回最初上传的 HTML/ZIP 和原始文件名；旧记录缺失文件名时按版本编号生成；预览失败不妨碍取回仍在的原件。
2. 每个原型使用持久化递增计数，保留已有编号，允许缺口，并发上传不重号；无法核实的已删除历史编号不编造，写入迁移说明。
3. 上传可选同一原型的成功版本作为比较基线，默认最近成功版本，保存实际关联；旧版无可信记录时显示“未记录”，不按编号减一推断。
4. 搜索区分资产信息命中和版本内容命中；前者进入资产详情，后者进入真实命中版本；错误与无结果提示分开。
5. 区分上传失败、原件已保存、预览处理中和预览失败；快照上线前使用“当前发布原型”，材料仍是可继续整理的工作资料。
6. 首次数据库结构迁移前完成数据库与文件一致性备份，并在独立环境恢复核对原件及关系。

本期不包含资料库重构、统一回收站、发布快照、比对页面和整体 UI 改版。

## 数据与接口演进原则

- 第二期：扩展删除、恢复、永久清理和导出接口；默认恢复期 30 天，恢复父级时保留子项原有删除状态。
- 第三期：引入“资料资产 → 不可变修订 → 工作引用”；每条旧材料先独立迁移，不按文件名自动合并，保留旧链接及原件。
- 第四期：引入发布快照及条目，当前发布指向快照，原型版本由快照派生，避免两套发布指针分别变化；旧记录不伪造历史材料清单。
- 第六至八期：比较结果绑定确定的内容、配置与规则；明确记录失败、跳过、不支持的部分。
- 每期同步更新共享类型、接口文档及必要迁移；涉及迁移时附备份与回退说明。

跨项目材料复用暂用显式复制并记录来源；原件不可覆盖，历史引用不自动升级。实时目录监听、团队协作、OCR 和 AI 整理作为后续候选，不计入当前八期承诺。

## 交付与推进

每期交付四项：已完成范围、可操作的验收步骤、测试结果、遗留问题及下一期建议。测试按当期变更选择：

| 期次 | 重点验证 |
| --- | --- |
| 第一期 | 原件哈希、下载权限、并发编号及删除后递增、历史搜索、基线展示 |
| 第二期 | 父子恢复关系、清理失败重试、导出完整性、空环境恢复 |
| 第三、四期 | 旧材料迁移、材料局部升级、发布后资料变化、整套回滚、引用保护 |
| 第五至八期 | 固定样本上的中文检索、表格浏览、文件差异、视觉稳定性和结构比较 |

按改动运行现有类型检查、测试与构建，并进行对应页面实际操作验证。不承诺未经评估的整套日历工期；后续结合实际投入再估算。

当前下一步是验收第一期并讨论第二期细化范围，尚未确认启动第二期。开发工作由其他会话按授权实施，产品规划会话维护规划及分析文档。
